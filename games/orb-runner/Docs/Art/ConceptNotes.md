# Orb Runner - Concept board notes

`ConceptBoard.png` (next to this file) is a top-down sketch of the arena with the style guide palette.

## What the board shows
- **Left:** the arena from above, at 1:10 scale. Slate walls, navy floor with the cyan grid, four violet pillars, eight cyan orbs (four on the edges, four in the corners), the amber player in the centre, the red drone in the north-west corner. Positions follow `Docs/Design/LevelLayout.md`.
- **Top right:** the seven palette swatches in style guide order.
- **Bottom right:** a value strip from dark to light. The environment sits in the three darkest steps; interactive things sit in the three brightest.

## Reading the board
At thumbnail size you should still be able to count the orbs and find the drone. If you cannot, the contrast rule in the style guide is being broken.
