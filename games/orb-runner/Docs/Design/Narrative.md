# Orb Runner - Narrative and on-screen text

## Premise (two sentences)
You are a recovery probe sent into a derelict containment grid to bring back eight memory orbs before the power fails. The grid's last security drone still thinks you are an intruder.

## Naming
| Thing | Name in text |
|---|---|
| Player health | HULL |
| Collectibles | ORBS |
| Enemy | the drone (never named on screen) |

## Exact on-screen text
| Where | Text |
|---|---|
| Score line | `SCORE <n>   ORBS LEFT <n>` |
| Timer | `TIME <m>:<ss>` |
| Health label | `HULL` |
| Win banner | `ALL ORBS RECOVERED` |
| Lose banner | `SIGNAL LOST` |

Upper case throughout, no punctuation. The same lose banner is used for running out of time and for losing all hull: from the probe's point of view both are a lost signal.
